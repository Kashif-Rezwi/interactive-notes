Part 1 · source cells 3–19

Mathematical foundations & notation

This part teaches the alphabet. Every formula in the later parts is spelled with these symbols — scalars, vectors, matrices, functions, and the summation sign — so fluency here pays off everywhere else.

Scalar source

A scalar is a single numerical value: a ∈ R.

In ML: scalars are often optimization parameters or evaluation metrics — learning rate, weight value, bias term, loss value.

Vector source

A vector is an ordered collection of numbers arranged in a single dimension:

x = [x1, x2, …, xn]T ∈ Rn

A vector represents: feature vectors, word embeddings, user representations, probability distributions, and hidden states in neural networks.

Source example: the vector [170, 65, 25]T could represent the height, weight, and age of a person in a dataset.

Matrix source

A matrix is a 2-dimensional arrangement of numbers: A ∈ Rm×n, where m = number of rows and n = number of columns.

In ML, matrix dimensions have a fixed interpretation
Matrix dimensionInterpretation
RowsSamples / observations
ColumnsFeatures

Source example: a 3×2 matrix such as rows [1, 2], [3, 4], [5, 6] represents 3 samples with 2 features. Datasets in ML pipelines are almost always represented as matrices.

Functions in machine learning source

A function maps inputs to outputs: f: Rn → R. This means the input is an n-dimensional vector and the output is a single real value.

Example — the linear model:

f(x) = wTx + b

where w = weights, x = feature vector, b = bias. This equation forms the foundation of linear regression, logistic regression, perceptrons, and neural networks — every neural network layer is essentially a sequence of linear transformations followed by non-linear activations.

Summation notation source

Summation notation provides a compact mathematical representation:

Σi=1n xi  =  x1 + x2 + … + xn

Meaning: add all elements from index 1 to n. It is used extensively in loss functions, gradient calculations, optimization equations, and statistical computations — so whenever you see Σ, read it as “add up”.

Important notation source

  • xT → transpose (flips rows and columns — explored in Part 5)
  • ‖x‖ → norm, a measure of vector size (explored in Part 3)

Proof intuition (interview skill) source

Interviewers often test conceptual understanding through small mathematical proofs. The source’s example is the linearity of the dot product:

(x + y) · z = x · z + y · z

The derivation only needs summation notation, so step through it below. (The dot product itself is defined in Part 3 — revisit this proof afterwards to see how the pieces lock together.)

Part 2 · source cells 20–26

Vector spaces & geometry

Now that vectors exist, where do they live, and which points can we reach with them? This part introduces the “space” in vector space and the four words that describe its shape: linear combination, span, basis, dimension.

Vector space source

A vector space is a collection of vectors with two operations — vector addition and scalar multiplication (multiplying a vector by a number) — that satisfy the closure properties: adding two vectors in the space stays in the space, scaling a vector stays in the space, and the space contains the zero vector.

Examples: R1 — the real line; R2 — the plane; R3 — 3-D space; Rn — n-dimensional space.

Connection to ML: feature space — every data point lives in some Rn, where n is the number of features.

Linear combination source

A vector b is a linear combination of vectors v1, …, vk if it can be written as:

b = a1v1 + a2v2 + … + akvk

where a1, …, ak are scalars. Every neural network layer computes linear combinations of its inputs (before the non-linear activation), which is why this operation is so central.

Source example: 2 · [1, 2] + 3 · [3, 1] = [2, 4] + [9, 3] = [11, 7]. The explorer below starts in exactly this state.

Span source

The span of a set of vectors is the set of all their linear combinations — everywhere you can reach by scaling and adding those vectors.

  • One non-zero vector in R2 → span is a line
  • Two non-parallel vectors in R2 → span is the whole plane
  • Two parallel vectors in R2 → span stays a line — the second direction adds nothing new

Basis & dimension source

A basis is a minimal set of linearly independent vectors that spans the space. Examples: the standard basis of R2 is {(1, 0), (0, 1)}; the standard basis of R3 is {(1, 0, 0), (0, 1, 0), (0, 0, 1)}. The dimension is the number of basis vectors — R2 has dimension 2, a plane has dimension 2.

Connection to ML: dimensionality — word embeddings are high-dimensional vectors in Rn, and PCA finds a lower-dimensional basis for the data. Linear independence is defined precisely in Part 6 — for now read it as “no vector in the set is redundant”.

Part 3 · source cells 29–35

Core operations: dot product, norms, orthogonality

These three operations turn vectors into numbers we can reason with: how aligned two vectors are, how big a vector is, and when two directions have nothing to do with each other.

Dot product source

The dot product has two equivalent faces.

Algebraic definition: multiply corresponding components and add:

x · y = Σi xiyi

Geometric definition:

x · y = ‖x‖ ‖y‖ cos θ

where θ is the angle between the vectors. Source example: (1, 2) · (3, 4) = 1·3 + 2·4 = 11.

Connection to ML: the dot product measures similarity — it powers attention mechanisms and cosine similarity, and it is the computation at the heart of every projection (Part 4). The proof you stepped through in Part 1 shows it is linear: (x + y) · z = x · z + y · z.

Norms — measuring vector size source

L2 norm (Euclidean): the straight-line length of the vector.

‖x‖2 = √( Σi xi2 )

L1 norm (Manhattan): the sum of absolute values — the “city block” distance.

‖x‖1 = Σi |xi|

Connection to ML: L2 is used in ridge regression for regularization and as a distance metric; L1 drives lasso regularization and feature selection because it pushes solutions toward sparsity.

Orthogonality source

Two vectors are orthogonal (perpendicular, at a right angle) exactly when their dot product is zero:

x · y = 0  ⇔  x ⊥ y

Why? From the geometric definition, cos 90° = 0. Connection to ML: orthogonality underlies feature decorrelation, the directions PCA chooses, and every projection — the error of a projection is always orthogonal to what it is projected onto (Part 4).

Part 4 · source cells 36–46

Projections & least squares

This is the geometric heart of the module: how to place one vector onto the direction of another, and why that exact move is what regression does when data is noisy.

Vector projection source

The projection of x onto the direction of y is the part of x that points along y:

projy(x) = x · yy · y y = x · y‖y‖2 y

The fraction x·yy·y is a scalar: how far along y the projection lands.

Orthogonal decomposition source

Every vector splits cleanly into the part along y plus the part left over:

x = x̂ + e,   where x̂ = projy(x) and e = x − x̂

The crucial property: the error e is orthogonal to y (e · y = 0). The projection is the closest point on the line through y to the tip of x — watch the right-angle marker in the explorer below.

Least squares & the normal equation source

When the system Ax = b has no exact solution (more equations than unknowns, noisy data), least squares finds the x that minimizes the sum of squared errors ‖Ax − b‖²:

x = (ATA)−1ATb

Geometric intuition from the source: Ax can only live in the span of A’s columns. The best approximation is the projection of b onto that span, and the residual b − Ax is orthogonal to every column of A — exactly the orthogonal decomposition above, scaled up from one direction to a whole column space. This is the geometric reason regression “minimizes error”.

Connection to ML: linear regression training is this formula in action; gradient descent iteratively searches for the same optimum.

Part 5 · source cells 47–55

Matrices as transformations

Until now matrices were data containers. Here they become machines: multiplying by a matrix moves, stretches, flips, or collapses every vector in space — the same operation a neural network layer applies to its input.

Matrix multiplication source

The entry in row i, column j of the product AB is the dot product of row i of A with column j of B:

(AB)ij = Σk AikBkj

Warning — order matters: in general AB ≠ BA. Matrix multiplication is not commutative; try the order-matters demo below.

Connection to ML: stacking transformations — and the weight multiplication in every fully connected layer.

Matrix–vector product source

Multiplying a matrix by a vector produces a linear combination of the matrix’s columns, weighted by the vector’s entries:

Ax = x1(col 1 of A) + x2(col 2 of A) + …

This closes a loop with earlier parts: the output Ax always lives in the span of A’s columns — which is exactly why least squares in Part 4 projects b onto that span. Connection to ML: the forward pass of a layer, y = Wx + b.

Identity matrix source

The identity matrix I has 1s on the diagonal and 0s everywhere else. It leaves every vector unchanged: Ix = x — the matrix equivalent of multiplying by 1. It is the “do nothing” transformation, and it appears in the normal equation via (ATA)−1.

Transpose source

The transpose flips rows and columns: (AT)ij = Aji. For vectors, xTx = ‖x‖² — the dot product of a vector with itself, the quantity that appeared under the fraction in the projection formula. The transpose is what builds ATA and ATb in the normal equation.

Symmetric matrices source

A matrix is symmetric when A = AT — it mirrors across its diagonal. The source notes a key property: symmetric matrices have real eigenvalues and orthogonal eigenvectors. Eigenvalues and eigenvectors are named here but not taught in the source — see the clearly marked supplemental box in Part 7. Notice that ATA from the normal equation is always symmetric.

Part 6 · source cells 56–62

Linear independence & rank

This part makes “redundant” a precise, measurable idea — and explains why data scientists care so much about it.

Linear independence source

A set of vectors is linearly independent if the only way to combine them into the zero vector is with all-zero scalars:

a1v1 + … + akvk = 0  only when  a1 = … = ak = 0

If some non-zero combination gives zero, the set is dependent — at least one vector can be written using the others, i.e. it is redundant. In R2: two vectors are dependent exactly when they are parallel (one is a scalar multiple of the other) — the same condition that shrank the span in Part 2.

Rank source

The rank of a matrix is the number of linearly independent columns (equivalently, rows) it has.

  • Full rank: every column adds a new direction — no redundancy. A 2×2 matrix with det ≠ 0 has rank 2.
  • Low rank: some columns are linear combinations of others — redundant features. The det = 0 transformations in Part 5 are exactly the low-rank ones.

Connection to ML: rank reveals feature redundancy. Multicollinearity — highly correlated features in a dataset — is low rank in practice: it destabilizes the inverse (ATA)−1 that the normal equation needs, making regression coefficients unreliable. PCA deliberately reduces rank to compress data while keeping most of its structure.

supplemental · not in source Eigenvectors & eigenvalues. The source names these in the table above (and states that symmetric matrices have real eigenvalues and orthogonal eigenvectors) but never defines them. For a square matrix A, a non-zero vector v is an eigenvector if multiplying by A only stretches it, without rotating it:

Av = λv

The stretch factor λ is the eigenvalue. In the transformation lab of Part 5, eigenvectors are the directions that keep pointing along themselves while everything else swings around them. PCA chooses the eigenvectors of the data’s covariance matrix as its new axes — which is why the source pairs eigenvectors with PCA.

Supplemental source: G. Strang, Introduction to Linear Algebra; 3Blue1Brown, Essence of Linear Algebra (eigenvectors/eigenvalues chapter). Full citations are recorded in the run ledger, not linked here.

supplemental · not in source PCA in one paragraph. Principal Component Analysis projects data onto fewer directions — the ones that preserve the most spread (variance) of the data. Those directions are the eigenvectors just defined. In this module’s vocabulary: PCA reduces the rank of the data matrix by projecting it onto a lower-dimensional basis, which is exactly projection (Part 4) applied to every data point at once.

Interview prep (from the source)

The source ends with interview questions that test exactly this module. Open each one and try to answer before revealing.

Q1. Explain the linearity of the dot product: (x + y) · z = x · z + y · z

Answer: write everything with summation notation: (x + y) · z = Σ(xi + yi)zi = Σ(xizi + yizi) = Σxizi + Σyizi = x·z + y·z. You already stepped through this in Interactive 3.

Q2. Give a concrete example showing why AB ≠ BA

Answer: take the 90° rotation A = [[0, −1], [1, 0]] and the shear B = [[1, 1], [0, 1]]. Then AB = [[0, −1], [1, 1]] but BA = [[1, −1], [1, 0]] — different matrices. Applied to (1, 0): rotate-then-shear gives (0, 1), shear-then-rotate gives (1, 1). Verified live in Interactive 9.

Q3. Geometrically, why does least squares minimize the error?

Answer: Ax can only reach the span of A’s columns. The closest reachable point to b is its projection onto that span, and at the closest point the residual b − Ax must be orthogonal to the span — if it had any component along a column direction, sliding x̂ that way would shorten the residual. This is the orthogonal decomposition of Part 4 scaled up to a column space. (This sentence-by-sentence argument is inferred from the source’s geometric intuition, which states the projection/orthogonality facts without spelling out the sliding argument.)

Summary

How the whole subject fits together

The one-sentence version: machine learning represents data as vectors, measures and compares them with dot products and norms, transforms them with matrices, and when exact answers are impossible, projects onto what is reachable — which is least squares, which is regression.

The dependency chain:

  1. Notation (scalars, vectors, matrices, Σ) gives the alphabet.
  2. Spaces say where vectors live and what combinations can reach (span, basis, dimension).
  3. Operations turn geometry into arithmetic: dot product (angle/similarity), norms (size), orthogonality (zero dot product).
  4. Projection uses the dot product to split any vector into “along the direction” plus “orthogonal error” — and least squares scales that move up to matrices via the normal equation x = (ATA)−1ATb.
  5. Transformations reinterpret matrices as motions of space (and warn that order matters), with the transpose and identity supplying the parts of the normal equation.
  6. Rank measures how many directions a transformation or dataset really has — the detector of redundancy and multicollinearity.
  7. The ML map pins each idea to its job: attention, regularization, PCA, regression, network layers.
Before / after: at the start of these notes the formula x = (ATA)−1ATb was opaque. Now you can read it piece by piece: ATA is a symmetric matrix built by the transpose; inverting it requires full rank (no multicollinearity); ATb is a vector of dot products between columns of A and b; and the whole expression is the coordinate of the projection of b onto the span of A’s columns — the best reachable answer when Ax = b has no exact solution.

Three takeaways to keep:

  • Dot product = similarity; zero dot product = orthogonal. Almost every “compare two things” operation in ML is a dot product in disguise.
  • Matrix × vector = linear combination of columns. The output of any layer, and any Ax, lives in the span of the columns — nothing else is reachable.
  • Least squares = projection + orthogonality. The residual being orthogonal to the column space is not a trick; it is the geometric meaning of “best possible”.
