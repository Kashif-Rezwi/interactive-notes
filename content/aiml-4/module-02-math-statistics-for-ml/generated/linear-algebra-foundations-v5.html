Building blocks & notation

Class core source Learn — three containers for numbers

A scalar is a single numerical value — a learning rate, a weight, a bias, a loss. We write a ∈ ℝ ("a lives in the real numbers"). constructed example A learning rate of 0.01 is a scalar; so is a final loss of 0.43.

A vector is an ordered collection of numbers in a single dimension: x = [x₁, x₂, …, xₙ]ᵀ ∈ ℝⁿ. Ordered means position carries meaning. source The notebook's example packs one person into a vector:

x = [170, 65, 25]ᵀ
x₁ = 170 height (cm) · x₂ = 65 weight (kg) · x₃ = 25 age (years). Read it as: one person, three features. Vectors also represent word embeddings, user profiles, probability distributions, and hidden states in neural networks (source, cell 7).

A matrix is a 2-dimensional arrangement of numbers, A ∈ ℝ^{m×n}: m rows and n columns. The ML reading (source, cell 10): rows are samples, columns are features — datasets in ML pipelines are almost always matrices.

Class core source Functions and the linear model

A function maps inputs to outputs. f : ℝⁿ → ℝ means: in goes an n-dimensional vector, out comes a single real number (source, cell 12). The notebook's central example is the linear model:

f(x) = wᵀx + b
w = weights (a vector) · x = feature vector · b = bias (a scalar) · wᵀx multiplies each feature by its weight and adds the results (you will compute this yourself in Unit 3). Foundation of linear/logistic regression, perceptrons, and every neural network layer — a linear transformation followed by a non-linear activation (source, cell 13).

Vector spaces, span, and independence

Class core source Learn — the playground and its legal moves

A vector space is a structure where two operations always stay inside the set: vector addition and scalar multiplication (cell 21). ℝ² — all 2-D vectors — is the example you can see. Combine those two legal moves and you get the workhorse of this lesson, the linear combination:

a₁x₁ + a₂x₂ + … + aₖxₖ
xᵢ = the vectors you combine · aᵢ = scalar weights, one per vector. Scale each vector, then add. Central to feature engineering, neural-network representations, embeddings, and PCA (cell 22); every linear-model prediction is a weighted linear combination of features.

The span of a set of vectors is every point you can possibly reach with linear combinations of them (cell 24). Two non-parallel vectors in 2-D span the entire plane.

Predict — the collapsing span

u = (2, 1) and v = (4, 2). Before touching the widget: what does the span of u and v cover?

v = 2·u — it points exactly along u, so scaling and adding never leaves that one direction: the span collapses to a line. Span is about independent directions, not vector count. Try it below: set v parallel to u and no choice of a, b leaves the line.

Class core source Independence, basis, dimension re-sequenced

repair R1 The source defines basis using "linearly independent" but teaches independence only in Part 6. Independence is taught here first, where it is load-bearing.

Vectors are linearly independent when the only way to make their combination equal zero is to set every weight to zero: a₁x₁ + … + aₙxₙ = 0 ⇒ all aᵢ = 0 (cells 58–59). Meaning: no vector can be built from the others — no redundancy. In 2-D, "independent" is exactly "not parallel".

A basis is the minimum set of independent vectors that still spans the space (cell 26) — no redundant members allowed. {(1,0), (0,1)} is the standard basis of ℝ². The dimension is how many basis vectors that takes: line → 1, plane → 2, space → 3 — and ML models routinely work in hundreds to millions of dimensions (cell 28).

Dot product, norms, and orthogonality

Class core source Learn — similarity as a number

The dot product multiplies matching components and adds the results — a summation from Unit 1 (cells 29–30):

x · y = Σᵢ xᵢyᵢ   =   ‖x‖ · ‖y‖ · cos θ
x, y = vectors · xᵢyᵢ = product of the i-th components · ‖x‖ = length of x (below) · θ = angle between the vectors. Two views of one number: component-wise arithmetic, and geometry — lengths times the cosine of the angle (cell 30).

Foundation supplemental cos θ in one breath: cosine measures alignment — 1 when vectors point the same way, 0 at a right angle, −1 when opposite. So the sign of the dot product is the sign of alignment: large positive → similar direction; zero → orthogonal; negative → opposite (cell 30).

Predict — can a dot product go negative?

x = (3, 1). You may rotate y anywhere. Can x · y ever be negative?

Yes. cos θ turns negative the moment θ passes 90°. Components multiply and add, and opposing components overpower the rest — try y = (−3, 0.5) in the widget.

Class core source Norms — length, two ways

A norm measures a vector's size (cells 31–32):

‖x‖₂ = √(Σᵢ xᵢ²)     ‖x‖₁ = Σᵢ |xᵢ|
‖x‖₂ (L2) = straight-line distance — used in gradient descent, regularization, distance metrics. ‖x‖₁ (L1) = sum of absolute components — used in sparse models, Lasso, feature selection (cells 31–32). flagged fix The source's L2 formula typography is mangled; the corrected form is shown.

Two vectors are orthogonal exactly when x · y = 0 — independent in direction (cells 33–34).

Class core source The interview proof re-sequenced

repair R3 The source's proof skill uses the dot product, so it lives here, after the operation it proves things about. Interviewers test understanding through small derivations (cells 18–19). Prove linearity: (x + y) · z = x · z + y · z.

(x + y) · z = Σᵢ (xᵢ + yᵢ)zᵢ = Σᵢ xᵢzᵢ + Σᵢ yᵢzᵢ = x · z + y · z
Step 1: expand with summation notation (Unit 1). Step 2: distribute zᵢ and split the sum. Step 3: recognize each sum as a dot product. This pattern — expand, distribute, regroup — powers gradient derivations, backpropagation proofs, and optimization theory (cell 19).

Class core source Matrix multiplication — and the order trap

Matrix multiplication combines transformations: C = AB applies B first, then A. Each entry of C is a dot product from Unit 3 — row of A · column of B. And the trap the source flags in capital letters (cell 48):

AB ≠ BA
Order matters significantly in ML pipelines (cell 48): scale-then-rotate is not rotate-then-scale, and a data pipeline's stages behave the same way.

Class core source Identity, transpose, symmetric

The identity matrix I behaves like multiplication by 1: Ix = x (cell 52) — used in inversion, optimization, and residual connections. The transpose swaps rows and columns: (Aᵀ)ᵢⱼ = Aⱼᵢ (cell 54) — central to covariance computation and backpropagation.

Projections & least squares

Class core source Learn — the shadow one vector casts on another

A projection measures how much of one vector lies along another (cell 37) — think of the shadow a casts onto the line of b. Foundation supplemental A unit vector is a vector of length 1: b̂ = b / ‖b‖ — "direction only." The projection length is a·b̂, which expands into the source's formula (transcribed from the notebook's image, cell 38 — figure not redistributed):

proj_b(a) = (a · b / b · b) · b
a·b = alignment of a with b (Unit 3) · b·b = ‖b‖², so the fraction is the shadow length measured in units of b · multiply by b to point that length along b. Applications: dimensionality reduction, signal processing, PCA, optimization (cell 39).

Orthogonal decomposition (cells 40–43, transcribed from the notebook's image): any vector splits as a = a∥ + a⊥ — a part along b (the projection) plus a part perpendicular to b. The perpendicular part satisfies a⊥ · b = 0, which is the geometric heart of regression error minimization (cell 43).

Class core source Least squares — best answer when no exact answer exists

Given Ax = b, an exact solution often does not exist — more equations than unknowns. Least squares finds the best approximate solution by minimizing squared error (cell 45). The error b − Ax is exactly the residual from the projection above: minimizing it makes it orthogonal to the columns of A — the decomposition doing real work.

x̂ = (AᵀA)⁻¹Aᵀb
Aᵀ = transpose (Unit 4) · AᵀA = a small square matrix built from dot products · ( )⁻¹ = inverse — Foundation supplemental the matrix that undoes another, so A⁻¹A = I; for the 2×2 system below the page solves it for you live · b = observed outputs · x̂ = best-fit parameters ("x-hat" — flagged fix the source writes plain x; the hat marks an estimate, standard notation).     Glossary

    scalar
    A single number.
    Precisely: an element of ℝ; scales vectors by multiplication.
    ML: learning rates, biases, loss values.
    vector
    An ordered list of numbers.
    Precisely: x = [x₁,…,xₙ]ᵀ ∈ ℝⁿ; position carries meaning.

    matrix
    A 2-D grid of numbers.
    Precisely: A ∈ ℝ^{m×n}; rows = samples, columns = features.
    ML: datasets and layer weights.
    summation (Σ)
    Add a run of terms.
    Precisely: Σᵢ₌₁ⁿ xᵢ = x₁ + … + xₙ.
    ML: loss functions, gradient formulas.
    transpose
    Swap rows and columns.
    Precisely: (Aᵀ)ᵢⱼ = Aⱼᵢ.
    ML: covariance, backpropagation, the normal equation.
    norm
    The size of a vector.
    Precisely: ‖x‖₂ = √(Σxᵢ²); ‖x‖₁ = Σ|xᵢ|.

    vector space
    A set closed under adding vectors and scaling them.
    Precisely: addition and scalar multiplication never leave the set.
    ML: the space features and embeddings live in.
    linear combination
    Scale vectors, then add them.
    Precisely: a₁x₁ + … + aₖxₖ.
    ML: every linear-model prediction; mixtures of features.
    span
    Everything reachable by linear combinations.
    Precisely: {a₁x₁ + … + aₖxₖ : aᵢ ∈ ℝ}.

    No vector is buildable from the others.
    Precisely: a₁x₁ + … + aₙxₙ = 0 only when all aᵢ = 0.

    basis
    The smallest spanning, independent set.
    Precisely: independent vectors whose span is the whole space.
    ML: coordinate systems for representations.
    dimension
    How many basis vectors a space needs.
    Precisely: the size of any basis.
    ML: embedding sizes, from tens to millions.
    dot product
    Multiply matching components and add.

    ML: similarity, attention scores, wᵀx in linear models.
    orthogonal
    At right angles; no shared direction.
    Precisely: x·y = 0.
    ML: independent components; residuals ⊥ fitted space.
    identity matrix
    The "multiply by 1" matrix.
    Precisely: Ix = x; ones on the diagonal, zeros elsewhere.
    ML: inversion, residual connections.
    symmetric matrix
    Equal to its own transpose.
    Precisely: A = Aᵀ; real eigenvalues, orthogonal eigenvectors.

    rank
    Number of independent columns.
    Precisely: the dimension of the column span.
    ML: feature redundancy, multicollinearity, PCA rank reduction.
