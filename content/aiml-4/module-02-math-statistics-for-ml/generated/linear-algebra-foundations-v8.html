Unit 1 · Learn

The three shapes of every dataset

Every dataset you will ever touch, and every number a model produces, comes in exactly three shapes: one number, a list of numbers, or a table of numbers.

The scalar — one lonely number Class coresource

A is a single numerical value, written a ∈ ℝ. No direction, no structure — just one number doing one job.

Tiny example. A learning rate of 0.01, a single weight w = 0.83, a bias b = 1.2, a loss of 2.4 — all scalars.

ML linkIn ML systems, scalars are the knobs and the gauges: optimization parameters (learning rate, weights, bias) and evaluation metrics (loss, accuracy).

The vector — a list where order is the meaning Class coresource

A is an ordered collection of numbers arranged in a single dimension:

x = [x₁, x₂, …, xₙ]ᵀ ∈ ℝⁿ

  • x — the whole vector, one object
  • x₁…xₙ — its entries, in a fixed order
  • ℝⁿ — "n-dimensional space": the set of all lists of n real numbers (Unit 2 unpacks this notation)
  • ᵀ — "transpose": the list written as a column; notation only for now, spotlighted in Unit 2

How to read the result: "x lives in a space of n-number lists." Nothing more is being claimed yet.

Tiny example (from class). x = [170, 65, 25]ᵀ can describe one person: height 170 cm, weight 65 kg, age 25. Three slots, three agreed meanings.

Misconception alert"Reordering a vector changes nothing." Swap the entries and [65, 170, 25]ᵀ is now a person who is 65 cm tall and weighs 170 kg — a completely different record. A vector is not a bag of numbers; slot positions carry meaning.

ML linksource Vectors carry everything in ML: feature vectors (one row of a dataset), word embeddings (a word as ~hundreds of numbers), user representations, probability distributions, and hidden states inside neural networks.

The matrix — the table ML runs on Class coresource

A is a 2-dimensional arrangement of numbers, written A ∈ ℝ^(m×n): m rows by n columns.

A = [ 1 2 ; 3 4 ; 5 6 ]  (3 rows × 2 columns)

  • m = 3 — number of rows → in ML, the samples / observations
  • n = 2 — number of columns → in ML, the features

How to read it: this table holds 3 things, each described by 2 numbers — e.g. three people, each with (height, weight).

Misconception alert"Rows are features, columns are samples." The ML convention is the opposite: rows are samples, columns are features. Each row is one complete observation; each column is one measured property across all observations.

ML linksource Datasets in ML pipelines are almost always represented as matrices — the whole pipeline speaks this table format.

Unit 2 · Learn

Compact math: Σ, ᵀ, and the equation ML runs on

Mathematicians hate writing long sums — so they invented compression. Three small pieces of notation will carry this entire course.

Summation: the for-loop of mathematics Class coresource

Σi=1n xi = x₁ + x₂ + … + xn

  • Σ (sigma) — "add them all up"
  • i = 1 under it — start counting at index 1
  • n on top — stop at index n
  • xi — the i-th element

How to read the result: one number — the total. If you can write a for-loop, you already understand Σ: initialize total = 0, loop, add.

Tiny example (from class). Σi=14 xi = x₁+x₂+x₃+x₄. With x = [5, 3, 8, 1]: 5+3+8+1 = 17.

Misconception alert"Σ multiplies the terms." It adds them. Σ of [2, 4, 6] is 2+4+6 = 12, not 2·4·6 = 48. (The multiplying cousin exists — it is written Π, and this course never needs it.)

ML linksource Σ is everywhere: loss functions sum errors over samples, gradients sum over features, statistics sum over data.

Transpose and ℝⁿ: two pieces of punctuation Class coresource · corrected typography flagged

The class's notation kit, unpacked: xᵀ ("x ") means the same list turned on its side — column becomes row, row becomes column. ‖x‖ means "the norm of x" — a length, coming in Unit 5. ℝⁿ means "all lists of n real numbers" — so x ∈ ℝ³ says x is a 3-number list.

Source fixes flagged hereThe class agenda says "Scaler" (typo for Scalar); the notebook prints ℝⁿ as "Rn" and breaks wᵀx across lines as "w T x". These notes use the standard forms throughout.

Functions: vector in, number out Class coresource

f : ℝⁿ → ℝ

  • f — the function, a machine
  • ℝⁿ — its input: an n-dimensional vector
  • ℝ — its output: a single real value

A model is exactly this: a feature vector goes in, one prediction comes out.

The linear model — as a weighted sum Class coresource · arc setup

f(x) = w₁x₁ + w₂x₂ + b

  • x₁, x₂ — the feature values (e.g. height, weight)
  • w₁, w₂ — the weights: how much each feature counts
  • b — the bias: a baseline added after the weighting

How to read the result: a score. Big weight × big feature = big contribution; the bias shifts everything up or down.

Tiny example. With w = [2, −1], x = [3, 4], b = 0.5: 2·3 + (−1)·4 + 0.5 = 6 − 4 + 0.5 = 2.5.

A promise this page will keepThe class writes this same equation as f(x) = wᵀx + b. That cryptic wᵀx is literally the weighted sum above, wearing a disguise we have not earned yet. Unit 6 will unmask it — once the dot product exists, the disguise becomes obvious. This equation founds linear regression, logistic regression, perceptrons, and neural networks; every neural network layer is a linear transformation followed by a non-linear activation.

Unit 3 · Learn

Combining vectors: from recipes to entire spaces

Take two vectors and a dial for each. Turn the dials and you can paint an entire plane — or, if the vectors line up, just a single line.

Vector spaces: where mixing is allowed Class coresource

A is a mathematical structure where two operations are always valid: vector addition (u + v) and scalar multiplication (a·v) — and the results stay inside the same space. ℝ², the set of all 2-D vectors, is the example to keep in your head: add or scale any 2-D vectors and you still have a 2-D vector.

Tiny example. [1, 2] + [3, 0] = [4, 2] and −2·[1, 2] = [−2, −4] — both still in ℝ². The space is closed under its two operations.

Linear combination: the recipe Class coresource

a₁x₁ + a₂x₂ + … + akxk

  • x₁ … xk — the ingredient vectors
  • a₁ … ak — the scalars: how much of each ingredient (the "dials")

How to read the result: a new vector — the dish the recipe cooks up. Scale each ingredient, then add.

Tiny example. 2·[1, 3] + (−1)·[0, 2] = [2, 6] + [0, −2] = [2, 4].

Misconception alert"The scalars aᵢ must be positive whole numbers." They can be any real numbers: negative (reverse the direction), zero (skip the ingredient), fractional (half as much).

ML linksource Linear combinations run feature engineering, neural-network representations, latent embeddings, and PCA. And notice: Unit 2's weighted sum w₁x₁ + w₂x₂ means every prediction in a linear model is a weighted linear combination of features.

Span: every dish those ingredients can make Class coresource

The of a set of vectors is the set of all possible linear combinations of them. If those combinations can generate an entire space, the vectors span that space. In class's words: two non-parallel vectors in 2-D span the entire plane.

ML linksource Feature representations span an information space; embeddings span a semantic space — what a model can express is bounded by what its building blocks span.

Misconception alert"Any two 2-D vectors span the whole plane." Only non-parallel pairs do. If one vector is a scaled copy of the other, every combination stays on their shared line — the prediction gate below tests exactly this.

Unit 4 · Learn

Independence, basis, dimension: the no-redundancy unit

A good team has no redundant member. A basis is exactly that: the smallest team of vectors that can still build everything.

Re-sequenced on purposeThe class defines basis in Part 2 "vectors must be linearly independent" — but teaches independence only in Part 6. Using a concept before teaching it breaks the dependency rule, so independence comes first here (repair R1), and basis follows legally.

Linear independence: the redundancy test Class coresource · moved, R1 · mangled layout transcribed + flagged

a₁x₁ + a₂x₂ + … + anxn = 0  ⟹  every ai = 0

  • x₁…xn — the vectors under test
  • a₁…an — scalars you are allowed to choose freely
  • ⟹ every ai = 0 — "the only way to reach the zero vector is to set every dial to zero"

How to read it: if no clever choice of scalars cancels the vectors out, then no vector in the set can be built from the others — no redundancy exists.

Tiny example (dependent). [1, 2] and [2, 4]: choose a₁ = 2, a₂ = −1 → 2·[1,2] + (−1)·[2,4] = [0,0]. A non-zero recipe reached zero, so the pair is dependent: [2,4] was just 2×[1,2] all along.

Tiny example (independent). [1, 0] and [0, 1]: a·[1,0] + b·[0,1] = [a, b], which is [0, 0] only when a = b = 0. No escape → independent.

Misconception alert"Vectors that look different are independent." [1, 2] and [2, 4] look different but are dependent — one is a scaled copy of the other. Independence is about directions, not appearance. (And any set containing the zero vector is automatically dependent: scale it by 5, scale the rest by 0, and you reach zero.)

Basis: the smallest spanning team Class coresource

A is the minimum set of vectors required to span a space. Two requirements, both now legal to say: the vectors must be linearly independent (no redundancy), and together they must still span the space (nothing left out). The standard basis of ℝ² is {(1,0), (0,1)} — the pure x-step and the pure y-step.

Misconception alert"Basis vectors must be unit length and perpendicular." Convenient, not required. [2, 1] and [1, 1] are neither unit nor perpendicular, yet they are independent and span ℝ² — a perfectly valid (skewed) basis.

Dimension: the headcount of a space Class coresource

The is the number of basis vectors required to represent a space: a line needs 1, a plane needs 2, 3-D space needs 3.

ML linksource Modern ML operates in hundreds, thousands, even millions of dimensions — a word embedding is a point in a space with one axis per learned meaning-dimension.

Unit 5 · Learn

Measuring vectors: how long? how far?

"How long is this vector?" has two honest answers — the straight line a crow flies, and the city-block walk a taxi drives. ML uses both, for different jobs.

The L2 norm: as the crow flies Class coresource · typography corrected + flagged

‖x‖₂ = √( x₁² + x₂² + … + xn² )

  • xᵢ² — each entry squared (negatives become positive; big entries count extra)
  • Σ … — add the squares
  • √ — take the square root, returning to ordinary units

Why it makes sense: it is Pythagoras. [3, 4] is the hypotenuse of a 3-4-5 triangle: √(9+16) = √25 = 5. How to read the result: straight-line distance from the origin — the vector's true geometric length.

The L1 norm: as the taxi drives Class coresource

‖x‖₁ = |x₁| + |x₂| + … + |xn|

  • |xᵢ| — absolute value: drop the sign (|−3| = 3)
  • Σ — add them all

Why it makes sense: on a city grid you cannot cut through blocks; you walk |east| + |north|. For [3, 4]: 3 + 4 = 7.

Misconception alert"‖x‖₁ just adds the entries." It adds the absolute values. ‖[−3, 4]‖₁ = 3 + 4 = 7, not −3 + 4 = 1. Signs never cancel inside a norm — every step counts.
ML linkL2 appears in gradient descent, regularization, and distance metrics. L1 drives sparse models, Lasso regression (regression with an L1 penalty), and feature selection — its absolute-value geometry pushes weak weights to exactly zero.

Unit 6 · Learn

Comparing vectors: the dot product

One number that tells you whether two vectors agree, disagree, or couldn't care less about each other.

The recipe: multiply matching slots, then add Class coresource · mangled layout transcribed + flagged

x·y = Σi xiyi = x₁y₁ + x₂y₂ + … + xnyn

  • xᵢyᵢ — multiply the two vectors' i-th entries
  • Σ — add those products
  • x·y — the dot product: a scalar, not a vector

Tiny example. [1, 2]·[3, 4] = 1·3 + 2·4 = 3 + 8 = 11.

The angle reading Class coresource Foundationsupplemental · cos θ primer

One-minute cos θ primer (the class assumed this): cosine measures an angle's "forwardness": cos 0° = 1 (same direction), cos 90° = 0 (perpendicular), cos 180° = −1 (opposite). It slides smoothly between.

x·y = ‖x‖ · ‖y‖ · cos θ

  • ‖x‖, ‖y‖ — the vectors' lengths (Unit 5)
  • θ — the angle between them

How to read the result (from class): large positive → similar direction · zero → orthogonal · negative → opposite direction.

Misconception alert — the magnitude confound"A bigger dot product means more similar direction." Not when lengths differ: [100, 0]·[100, 0] = 10 000 (same direction), but [3, 4]·[4, −3] = 0 (perpendicular!) — the giant score won only because the vectors are long. The fix: divide the lengths away — cosine similarity = (x·y) / (‖x‖‖y‖) = cos θ, a pure direction score between −1 and 1.

ML linksource + supplemental mechanism Dot products measure similarity (and drive attention in transformers — a query asks "which keys point my way?"). Because embeddings have different lengths, practice uses cosine similarity: the confound-free version.

Orthogonality: total disagreement Class coresource

Two vectors are exactly when x·y = 0 — perpendicular directions, each carrying zero of the other. Check: [1, 2]·[2, −1] = 2 − 2 = 0. Orthogonal vectors are independent in direction.

Misconception alert"x·y = 0 means one vector is the zero vector." No — [1,2] and [2,−1] are both non-zero, yet their dot product is 0 because they are perpendicular. Zero dot product is about angle, not emptiness.

The reveal: wᵀx was a dot product all along Deep divearc payoff · promised in Unit 2

Payoff — Unit 2's promise, keptUnit 2 wrote the linear model as a weighted sum: f(x) = w₁x₁ + w₂x₂ + b. Expand the dot product of w and x: w·x = w₁x₁ + w₂x₂. Identical! The class's compact form f(x) = wᵀx + b is the weighted sum wearing its formal disguise: wᵀ turns the column w sideways so it can "sweep across" x, multiplying matching slots and summing — which is the dot product. Every prediction of a linear model is one dot product of weights and features.
Interview skill (collapsed by default): prove the dot product is linear — (x+y)·z = x·z + y·z Class coresource · moved, R3

source, re-sequenced: in the notebook this proof sits in Part 1, before the dot product exists; it is legal only now (repair R3).

  1. Start from the definition: (x+y)·z = Σi (xᵢ + yᵢ) zᵢ
  2. Distribute the zᵢ: = Σi (xᵢzᵢ + yᵢzᵢ)
  3. Split the sum: = Σi xᵢzᵢ + Σi yᵢzᵢ
  4. Recognize the two dot products: = x·z + y·z ∎

Interviewers love this shape of argument: expand with Σ, distribute, regroup. The same three moves drive gradient derivations and backpropagation proofs.

Unit 7 · Learn

A matrix is a verb: it moves space

Stop reading a matrix as a table. Read it as a machine: feed it a vector and it rotates, stretches, shears, or squashes it somewhere new.

Re-sequenced on purposeThe class teaches projections and least squares (Part 4) before matrices (Part 5) — but the normal equation x̂ = (AᵀA)⁻¹Aᵀb needs transposes and matrix multiplication. Matrices come first here (repair R2), so Unit 8's climax is fully legal.

The matrix-vector product: the machine runs Class coresource

A·x  — each row of A dots with x

  • A — an m×n matrix (the machine)
  • x — an n-vector (the input)
  • result — an m-vector; entry i = (row i of A)·x, a dot product you already know (Unit 6)

Tiny example. A = [[1, 2], [0, 1]], x = [3, 1]: row 1 → 1·3 + 2·1 = 5; row 2 → 0·3 + 1·1 = 1. So Ax = [5, 1].

Deep divesupplemental Watch the columns: A's first column is exactly where the x-axis step e₁ = [1,0] lands, and the second column is where e₂ = [0,1] lands. A matrix is its columns' destinations — the playground below makes this visible.

ML linksource Neural network layers internally perform repeated matrix-vector multiplications: Ax is rotation, scaling, projection — the layer's "linear transformation" half.

Multiplying matrices: chaining machines Class coresource

C = AB builds one machine that does B first, then A — it combines transformations. Entry (i,j) of C is (row i of A)·(column j of B).

Worked example (constructed). A = [[1,2],[3,4]], B = [[0,1],[1,0]]:
AB = [[1·0+2·1, 1·1+2·0], [3·0+4·1, 3·1+4·0]] = [[2, 1], [4, 3]]
BA = [[0·1+1·3, 0·2+1·4], [1·1+0·3, 1·2+0·4]] = [[3, 4], [1, 2]]

Misconception alert"AB = BA — numbers commute, so matrices must too." The computed pair above disagrees: AB = [[2,1],[4,3]] but BA = [[3,4],[1,2]]. Order matters because "rotate then scale" is a different journey from "scale then rotate" — and ML pipelines chain transformations, so order matters significantly there too.

Shadows, errors, and the birth of linear regression

When no line fits the data, geometry picks the least-wrong one — and the tool it uses is a shadow.

Projection: the shadow one vector casts on another Class coresource · formula transcribed from the class figure (not redistributed) + flagged

projy(x) = x·yy·y · y

  • x·y — how much x and y cooperate (Unit 6)
  • y·y = ‖y‖² — normalizes by y's own length, so the answer doesn't depend on it
  • the fraction c = (x·y)/(y·y) — a scalar: "how many y-lengths of x point along y"
  • · y — stretch y by that scalar: the shadow itself, a vector along y

Why it makes sense: shine a light perpendicular to y; x's shadow is the part of x that "lies along" y. How to read the result: a vector parallel to y — x's best representative on y's line.

Tiny example. Project x = [2, 2] onto y = [4, 0] (the x-axis): c = (2·4 + 2·0)/(4·4 + 0·0) = 8/16 = 0.5, so proj = 0.5·[4,0] = [2, 0]. The leftover is e = x − x̂ = [0, 2] — straight up.

Orthogonal decomposition: every vector splits Class coresource · transcribed from the class figure (not redistributed) + flagged

x = x̂ + e,   with x̂ ∥ y and e ⊥ y

  • x̂ ("x hat") — the projection: the part along y
  • e — the leftover: the part perpendicular to y

Why it matters: "the part we can explain with y" plus "the part we cannot" — this is the geometric intuition behind regression error minimization, and the explorer above just proved the split is always clean (e·y = 0, x̂ + e = x, live).

Misconception alert"The leftover e can point in any direction." Never: e is always exactly perpendicular to y (e·y = 0). If it leaned even slightly along y, the shadow could move closer to x — so it was not the closest point.

Least squares: fitting when no fit exists Class coresource · duplicated/mangled layout transcribed once + flagged

We want Ax = b — but with real data an exact solution usually does not exist (more equations than unknowns; the points never lie on one line). finds the best approximate solution by minimizing the squared error.

x̂ = (AᵀA)⁻¹ Aᵀ b   (the normal equation)

  • Aᵀ — A transposed (Unit 7): it turns the over-tall system into a square, solvable one
  • AᵀA — a small square matrix; (·)⁻¹ — its inverse, the "undo" matrix
  • x̂ — the best approximate solution (the hat matters: it is usually not an exact solution of Ax = b — the source writes x; flagged)
Foundation bridge — the inverse, in one minutesupplemental Multiplying by the inverse M⁻¹ undoes M, like dividing by a number. For a 2×2 matrix [[a,b],[c,d]] the inverse exists exactly when ad − bc ≠ 0. When that flip-ability number is 0, the matrix squashes space flat (Unit 7's "collapse" preset) and cannot be undone — Unit 9 names the culprit: redundant columns.

Worked example (constructed) — four points (1, 2), (2, 3), (3, 3), (4, 5), fit y = mx + c by least squares. The normal equation for a line reduces to:
m = (n·Σxy − Σx·Σy) / (n·Σx² − (Σx)²) = (4·37 − 10·13) / (4·30 − 100) = 18/20 = 0.9
c = (Σy − m·Σx)/n = (13 − 9)/4 = 1.0
Best line: y = 0.9x + 1.0. Squared errors: (2−1.9)² + (3−2.8)² + (3−3.7)² + (5−4.6)² = 0.01 + 0.04 + 0.49 + 0.16 = SSE = 0.70 — the smallest any straight line can achieve on these points.

Misconception alert"The best-fit line passes through every point." Almost never — no straight line can. Least squares minimizes the total squared miss; here the line passes through none of the four points and that is still optimal.

Unit 9 · Learn

Rank: redundancy, measured

Redundancy has a number. Rank counts the truly independent columns — and it decides whether Unit 8's normal equation can even run.

Rank: the independent headcount Class coresource

The of a matrix is the number of linearly independent columns (or rows) in it — Unit 4's test, applied to columns. Full rank → no redundancy; low rank → redundant features.

Tiny example. A = [[1, 2], [2, 4], [3, 6]]: column 2 = 2 × column 1, so only one independent column → rank 1. Swap in a fresh second column, [[1, 0], [0, 1], [2, 3]]: neither column is a multiple of the other → rank 2 (full, for a 3×2 matrix).

Misconception alert"A 3×2 matrix has rank 3." Impossible: rank ≤ min(rows, columns) — three rows cannot give two columns more than 2 independent directions. Rank counts independent columns, not entries.
Closing the Unit 8 loopThe normal equation needs (AᵀA)⁻¹ — and that inverse exists exactly when A's columns are independent (full column rank). Unit 7's "collapse" preset and Unit 4's zero-hunt were the same story in costume: a redundant column flattens AᵀA, its flip-ability number hits 0, and the equation cannot be undone.
Misconception alert — multicollinearity"A duplicate feature is harmless — it's the same information twice." It is actively harmful: columns height-in-cm and height-in-m (= cm ÷ 100) are dependent, so the matrix is rank-deficient and (AᵀA)⁻¹ fails. This is the problem; PCA reduces rank on purpose to remove such redundancy.

Glossary — every term this lesson uses

Every dotted term in the lesson opens the matching entry below. Six fields each: simple, precise, intuition, example, related, and where it appears in practice.

Scalar

Simple: one single number.

Precise: an element of ℝ — a value with no direction or structure.

Intuition: a knob or a gauge: it sets one thing or reads one thing.

Example: learning rate 0.01; loss 0.47.

Related: vector, matrix (scalars are their building blocks).

Where it appears: Unit 1; ML optimization parameters and evaluation metrics.

Vector

Simple: an ordered list of numbers.

Precise: x = [x₁,…,xₙ]ᵀ, an element of ℝⁿ.

Intuition: a recipe card — slot position carries the meaning.

Example: [170, 65, 25]ᵀ = height, weight, age.

Related: scalar, matrix, feature, embedding.

Where it appears: Units 1–9; feature vectors, embeddings, hidden states.

Matrix

Simple: a table of numbers.

Precise: A ∈ ℝ^(m×n) — m rows, n columns.

Intuition: a spreadsheet where rows are samples and columns are features; also (Unit 7) a machine that moves space.

Example: a 3×2 table of 3 people × (height, weight).

Related: vector, rank, transpose, matrix multiplication.

Where it appears: Units 1, 7–9; datasets and neural-network layers.

Feature

Simple: one measured property of a sample.

Precise: one column of the data matrix; one entry of a feature vector.

Intuition: a question you ask every sample: "how tall? how heavy?"

Example: height in the person dataset.

Related: sample, vector, matrix, multicollinearity.

Where it appears: Units 1, 8, 9; feature engineering and selection.

Sample

Simple: one observation — one "thing" in the dataset.

Precise: one row of the data matrix.

Intuition: one form filled out; one person measured.

Example: the row [170, 65, 25] for one person.

Related: feature, matrix, vector.

Where it appears: Units 1, 8; training data everywhere in ML.

Function

Simple: a machine mapping inputs to outputs.

Precise: f: ℝⁿ → ℝ — an n-vector in, one real number out.

Intuition: a vending machine: features in, a score out.

Example: f([170, 65, 25]) → predicted risk score.

Related: linear model, weights, bias.

Where it appears: Unit 2; every ML model is one.

Linear model

Simple: prediction = weighted sum of features + baseline.

Precise: f(x) = wᵀx + b = w₁x₁ + … + wₙxₙ + b.

Intuition: each feature votes, weighted by importance; b sets the baseline.

Example: 2·height + (−1)·weight + 0.5.

Related: dot product, weights, bias, least squares.

Where it appears: Units 2, 6 (the wᵀx reveal), 8; regression, perceptrons, NN layers.

Weights

Simple: how much each feature counts.

Precise: the vector w in f(x) = wᵀx + b, learned from data.

Intuition: volume knobs, one per feature.

Example: w = [2, −1] doubles the first feature, discounts the second.

Related: linear model, bias, regularization.

Where it appears: Units 2, 6, 8; training tunes them.

Bias

Simple: a baseline added after the weighting.

Precise: the scalar b in f(x) = wᵀx + b.

Intuition: the answer before you know anything about the input.

Example: b = 0.5 shifts every prediction up by half a point.

Related: weights, linear model.

Where it appears: Unit 2; every linear/NN layer.

Summation (Σ)

Simple: "add them all up".

Precise: Σᵢ₌₁ⁿ xᵢ = x₁ + … + xₙ.

Intuition: a for-loop with a running total.

Example: Σᵢ₌₁⁴ of [5,3,8,1] = 17.

Related: index, dot product, least squares.

Where it appears: Unit 2; loss functions, gradients, statistics.

Index

Simple: the counter under Σ.

Precise: i runs from the lower limit to the upper limit, naming each term xᵢ.

Intuition: the loop variable.

Example: in Σᵢ₌₁⁴ xᵢ, i takes values 1, 2, 3, 4.

Related: summation.

Where it appears: Unit 2; everywhere Σ does.

Transpose

Simple: flip rows and columns.

Precise: (Aᵀ)ᵢⱼ = Aⱼᵢ; for a vector, xᵀ turns the column into a row.

Intuition: rotate the table's axes; row 1 becomes column 1.

Example: [[1,2,3],[4,5,6]]ᵀ = [[1,4],[2,5],[3,6]].

Norm

Simple: the length of a vector.

Precise: a function ‖x‖ assigning a non-negative size; L1 and L2 are the two this course uses.

Intuition: "how much vector is there?" — two honest ways to measure.

Example: ‖[3,4]‖₂ = 5, ‖[3,4]‖₁ = 7.

ℝⁿ (n-dimensional space)

Simple: all possible lists of n real numbers.

Precise: the set {(x₁,…,xₙ) : xᵢ ∈ ℝ}.

Intuition: the "universe" a vector lives in; ℝ² is the plane.

Example: [170, 65, 25] lives in ℝ³.

Related: vector, dimension, vector space.

Where it appears: Units 1–4; embeddings live in high-dimensional ℝⁿ.

Vector space

Simple: a set of vectors where adding and scaling always stay inside.

Precise: a set closed under vector addition and scalar multiplication.

Intuition: a playground you can never fall out of by mixing its members.

Example: ℝ² — mix any 2-D vectors, get a 2-D vector.

Related: ℝⁿ, linear combination, span.

Where it appears: Unit 3; the stage for everything else.

Linear combination

Simple: scale some vectors and add them.

Precise: a₁x₁ + a₂x₂ + … + aₖxₖ for any real scalars.

Intuition: a recipe: ingredients are vectors, scalars are amounts.

Example: 2·[1,3] + (−1)·[0,2] = [2,4].

Related: span, basis, linear model.

Where it appears: Unit 3; predictions, embeddings, PCA.

Span

Simple: everything a set of vectors can build.

Precise: the set of all their linear combinations.

Intuition: the territory the ingredients can paint — a plane, or only a line if they line up.

Example: [1,0] and [0,1] span all of ℝ²; [1,2] and [2,4] span only a line.

Related: linear combination, basis, rank.

Where it appears: Units 3–4; what a model can express.

Basis

Simple: the smallest team that can build everything.

Precise: a linearly independent set that spans the space.

Intuition: a minimal toolkit — remove one tool and something becomes unbuildable.

Example: {(1,0), (0,1)} for ℝ²; also {[2,1], [1,1]}.

Related: span, linear independence, dimension.

Where it appears: Unit 4; coordinate systems everywhere.

Dimension

Simple: how many basis vectors a space needs.

Precise: the size of any basis of the space.

Intuition: how many independent dials the space has.

Example: a line has dimension 1; a plane 2; ML embeddings often 768+.

Related: basis, ℝⁿ, rank.

Where it appears: Unit 4; embedding sizes in ML.

Linear independence

Simple: no vector in the set can be built from the others.

Precise: a₁x₁ + … + aₙxₙ = 0 forces every aᵢ = 0.

Intuition: the zero-hunt test: the only way to reach zero is "all dials at zero".

Example: [1,0] and [0,1] independent; [1,2] and [2,4] not.

Related: dependent vectors, basis, rank.

Where it appears: Units 4, 9; redundancy checks in ML features.

Dependent vectors

Simple: a set with a redundant member.

Precise: some non-zero choice of scalars makes a₁x₁ + … + aₙxₙ = 0.

Intuition: one vector is secretly a recipe of the others.

Example: [1,2], [2,4] — the second is 2× the first.

Related: linear independence, zero vector, rank.

Where it appears: Units 4, 9; multicollinearity.

Zero vector

Simple: the all-zeros vector, 0 = [0,…,0].

Precise: the additive identity: x + 0 = x.

Intuition: standing still; "no movement in any direction".

Example: [0, 0] in ℝ².

Related: linear independence (any set containing it is dependent), orthogonality.

Where it appears: Units 4, 6; the target of the independence test.

Dot product

Simple: multiply matching slots, then add.

Precise: x·y = Σᵢ xᵢyᵢ = ‖x‖‖y‖cos θ — a scalar.

Intuition: an agreement score between two directions.

Example: [1,2]·[3,4] = 11.

Related: norm, orthogonality, cosine similarity, projection.

Where it appears: Units 6–8; similarity search, attention.

Orthogonality

Simple: perpendicular vectors.

Precise: x and y are orthogonal iff x·y = 0.

Intuition: total directional disagreement — each carries none of the other.

Example: [1,2] and [2,−1]: dot product 0.

Related: dot product, projection, residual.

Where it appears: Units 6, 8; independent components.

L2 norm

Simple: straight-line length.

Precise: ‖x‖₂ = √(Σᵢ xᵢ²).

Intuition: Pythagoras: the crow-fly distance from the origin.

Example: ‖[3,4]‖₂ = 5.

Related: norm, L1 norm, dot product.

Where it appears: Unit 5; gradient descent, ridge regularization, distances.

L1 norm

Simple: city-block length.

Precise: ‖x‖₁ = Σᵢ |xᵢ|.

Intuition: the taxi distance: east block + north block, no cutting through.

Example: ‖[−3,4]‖₁ = 7 (not 1!).

Related: norm, L2 norm, sparsity.

Where it appears: Unit 5; Lasso, sparse models, feature selection.

Cosine similarity

Simple: the dot product with lengths divided out.

Precise: (x·y)/(‖x‖‖y‖) = cos θ, in [−1, 1].

Intuition: a pure direction score, immune to the magnitude confound.

Example: [1,0] vs [1,1] → cos θ ≈ 0.707.

Related: dot product, norm, embedding.

Where it appears: Unit 6; embedding search, recommendation.

Projection

Simple: the shadow of one vector on another.

Precise: proj_y(x) = ((x·y)/(y·y))·y.

Intuition: the part of x that lies along y's line.

Example: projecting [2,2] onto [4,0] gives [2,0].

Related: dot product, orthogonal decomposition, least squares.

Where it appears: Unit 8; PCA, signal processing, optimization.

Residual

Simple: the leftover after projecting.

Precise: e = x − x̂, always orthogonal to the projection direction.

Intuition: the part of x that the direction y cannot explain.

Example: x=[2,2] on y=[4,0] → e=[0,2], and e·y = 0.

Related: projection, orthogonality, least squares.

Where it appears: Unit 8; regression errors.

Orthogonal decomposition

Simple: splitting a vector into shadow + leftover.

Precise: x = x̂ + e with x̂ ∥ y and e ⊥ y.

Intuition: "explained by y" plus "unexplained by y".

Example: [2,2] = [2,0] + [0,2] relative to the x-axis.

Related: projection, residual, least squares.

Where it appears: Unit 8; the geometry behind regression.

Least squares

Simple: the best approximate answer when no exact one exists.

Precise: minimize ‖Ax − b‖₂² over x; solved by the normal equation.

Intuition: minimize the total area of the error squares.

Example: points (1,2),(2,3),(3,3),(4,5) → y = 0.9x + 1.0, SSE = 0.70.

Related: normal equation, residual, projection.

Where it appears: Unit 8; linear regression.

Normal equation

Simple: the one-move formula for the least-squares solution.

Precise: x̂ = (AᵀA)⁻¹Aᵀb.

Intuition: multiply by Aᵀ to get a square system, then undo AᵀA.

Example: the Unit 8 line fit (m = 0.9, c = 1.0).

Matrix multiplication

Simple: chaining two transformation machines.

Precise: (AB)ᵢⱼ = (row i of A)·(column j of B); not commutative.

Intuition: do B first, then A — order changes the journey.

Example: [[1,2],[3,4]]·[[0,1],[1,0]] = [[2,1],[4,3]], but swapping gives [[3,4],[1,2]].

Related: matrix, transpose, identity matrix.

Where it appears: Unit 7; stacked neural-network layers.

Identity matrix

Simple: the matrix that changes nothing.

Precise: I has 1s on the diagonal, 0s elsewhere; Ix = x.

Intuition: multiplication by 1, for vectors.

Example: [[1,0],[0,1]]·[3,4] = [3,4].

Related: matrix multiplication, inverse (normal equation).

Where it appears: Unit 7; inversion, optimization, residual connections.

Symmetric matrix

Simple: a matrix equal to its own transpose.

Precise: A = Aᵀ — mirrored across the diagonal.

Intuition: entry (i,j) always equals entry (j,i).

Example: the covariance matrix; [[2,1],[1,3]].

Related: transpose, eigenvectors (extension).

Where it appears: Unit 7; PCA and spectral methods stand on its properties.

Rank

Simple: the number of independent columns.

Precise: the count of linearly independent columns (or rows) of a matrix.

Intuition: how many genuinely different directions the columns cover.

Example: [[1,2],[2,4],[3,6]] has rank 1.

Related: linear independence, full rank, multicollinearity.

Where it appears: Unit 9; feature redundancy, PCA.

Full rank

Simple: no column is redundant.

Precise: rank equals min(rows, columns) — the maximum possible.

Intuition: every column pulls its own weight.

Example: [[1,0],[0,1],[2,3]] has full rank 2.

Related: rank, normal equation (its inverse needs full column rank).

Where it appears: Unit 9; when least squares can run.

Multicollinearity

Simple: features that duplicate each other.

Precise: a column (near-)equal to a linear combination of others → rank-deficient A, (AᵀA) non-invertible.

Intuition: measuring height in cm and in meters — two columns, one fact.

Example: height_cm and height_m columns.

Related: rank, full rank, least squares.

Where it appears: Unit 9; a classic regression failure mode.

Embedding

Simple: a thing turned into a vector of learned numbers.

Precise: a map from items (words, users) to points in ℝⁿ.

Intuition: a meaning-coordinate system: similar things land near each other.

Example: a word as 768 numbers.

Related: vector, cosine similarity, dimension.

Where it appears: Units 1, 6, 10; search, recommendation, LLMs.

PCA (principal component analysis)

Simple: compressing data onto its most informative directions.

Precise: projecting onto top eigen-directions of the covariance matrix (a later course makes this precise).

Intuition: keep the shadow, drop the leftover — on purpose.

Example: squashing 768-D embeddings to 2-D for a plot.

Related: projection, rank, symmetric matrix.

Where it appears: Units 8–10 (extension pointer); dimensionality reduction.
