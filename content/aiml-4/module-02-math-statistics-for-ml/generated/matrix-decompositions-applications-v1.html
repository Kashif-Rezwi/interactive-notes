CLASS CORE
UNIT 1 · INVARIANT DIRECTIONS

Some vectors keep their direction

Most transformations turn a vector and stretch it. An eigenvector is a nonzero direction that survives without turning; its eigenvalue is the scale.

Av = λv
A: matrix transformation · v: eigenvector · λ: eigenvalue scale. Read it as “apply A, or scale v by λ, and get the same result.”

UNIT 2 · DIAGONALIZATION

Change coordinates so powers become easy

If independent eigenvectors form the columns of P, a matrix can be rewritten using a diagonal matrix D of eigenvalues. Diagonal entries do not mix; they simply power themselves.

A = P D P⁻¹
P: eigenvector coordinates · D: diagonal eigenvalue matrix · P⁻¹: change back. The equation says “move into eigen-coordinates, compute, then return.”
Dⁿ = diag(d₁ⁿ, d₂ⁿ, …)
n: repeated applications · dᵢ: diagonal scale. Each direction can be powered independently.

UNIT 3 · SINGULAR VALUE DECOMPOSITION

Every matrix gets three readable stages

SVD works for rectangular matrices too. It describes an input direction system V, axis-wise scales Sigma, and an output direction system U.

A = UΣVᵀ
U: left/output directions · Σ: nonnegative singular values · Vᵀ: right/input directions. Read left to right as rotate, scale, rotate.

UNIT 4 · PCA CONNECTION

PCA keeps the directions with the most variance

After centering a data matrix X, PCA looks for principal directions that capture variation. In SVD, those directions appear in V; larger singular values carry more variance scale.

C = (1/n)XᵀX
C: covariance matrix · X: centered data · n: number of samples. Centering makes the origin the data mean.
X = UΣVᵀ
Columns of V: principal directions · σᵢ²: variance scale associated with direction i.

UNIT 5 · LOW-RANK APPROXIMATION

Keep a few directions, accept bounded loss

A rank-k approximation stores only the first k singular directions. This can compress an image, expose a recommender's latent preferences, or reduce an embedding while discarding less dominant detail.

Aₖ = UₖΣₖVₖᵀ
k: number of retained components; the subscript k means every factor is truncated to those components.

GLOSSARY

Terms used in this lesson

eigenvector
Simple: a direction a matrix does not turn. Precise: a nonzero v with Av=λv. Example: [1,0] for diag(2,3). Related: eigenvalue. ML use: principal directions.
eigenvalue
Simple: the scale on an invariant direction. Precise: λ in Av=λv. Example: 2 for [1,0]. Related: spectrum. ML use: covariance analysis.
spectrum
Simple: the list of eigenvalues. Precise: roots of the characteristic equation. Example: {2,3}. Related: eigenvalue. ML use: spectral methods.
diagonalization
Simple: changing coordinates to independent eigen-directions. Precise: A=PDP⁻¹. Example: powers of D. Related: basis. ML use: stability analysis.
SVD
Simple: direction, scale, direction. Precise: A=UΣVᵀ for rectangular or square A. Example: three-stage strip. Related: singular value. ML use: compression.
singular value
Simple: strength of a directional component. Precise: nonnegative diagonal entry of Σ. Example: 5 and 2. Related: rank. ML use: denoising.
covariance
Simple: how centered features vary together. Precise: C=(1/n)XᵀX here. Example: PCA input. Related: variance. ML use: feature geometry.
PCA
Simple: ordered directions that preserve variance. Precise: projection onto principal directions. Example: columns of V for centered X. Related: SVD. ML use: dimensionality reduction.
rank
Simple: number of independent directions. Precise: dimension of the column space. Example: rank-k retains k components. Related: low rank. ML use: redundancy.
latent factor
Simple: hidden lower-dimensional cause. Precise: an unobserved direction explaining correlated observations. Example: user preference. Related: embedding. ML use: recommendation.
