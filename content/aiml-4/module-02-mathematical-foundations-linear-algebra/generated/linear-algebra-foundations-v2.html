Part 1 · Mathematical foundations & notation

Scalars, vectors, matrices

Scalar. A single numerical value, a ∈ R. In ML systems scalars appear as optimization parameters or evaluation metrics: learning rate, a weight value, a bias term, a loss value.
Vector. An ordered collection of numbers arranged in a single dimension, x = [x₁, x₂, …, xₙ]ᵀ ∈ Rⁿ. Vectors represent feature vectors, word embeddings, user representations, probability distributions, and hidden states in neural networks.

Source example
x = [170, 65, 25]ᵀ could represent a person's height, weight, and age in a dataset.

Matrix. A 2-dimensional arrangement of numbers, A ∈ R^(m×n), where m is the number of rows and n the number of columns. In ML, rows are samples/observations and columns are features; datasets in ML pipelines are almost always represented as matrices.

Source example
A 3×2 matrix with rows [1, 2], [3, 4], [5, 6] represents 3 samples and 2 features.

Functions in machine learning

A function maps inputs to outputs: f : Rⁿ → R — the input is an n-dimensional vector, the output a single real value.

Linear model. f(x) = wᵀx + b, where w = weights, x = feature vector, b = bias. This is the basis of linear regression, logistic regression, perceptrons, and neural networks. Every neural network layer is essentially a sequence of linear transformations followed by non-linear activations.

Summation notation

Summation notation provides a compact mathematical representation: Σᵢ₌₁ⁿ xᵢ means "add all elements from index 1 to n". It is used extensively in loss functions, gradient calculations, optimization equations, and statistical computations.

Interactive · Summation expander constructed example

Important notation

  • xᵀ → transpose
  • ‖x‖ → norm
  • Rⁿ → n-dimensional space
Proof intuition (interview skill): linearity of the dot product

Interviewers often test conceptual understanding through small mathematical proofs. Claim: (x + y)·z = x·z + y·z.

Such derivations are important in gradient derivations, backpropagation proofs, optimization theory, and ML interviews. This property is known as linearity.

Part 2 · Vector spaces & geometry

Vector space. A mathematical structure where vector addition and scalar multiplication are valid. If vectors remain inside the same space after these operations, the set forms a vector space. Example: R² contains all 2D vectors.
Linear combination. Formed by scaling vectors and adding them together: a₁x₁ + a₂x₂ + … + aₖxₖ. Central to feature engineering, neural network representations, latent embeddings, and PCA. Every prediction in a linear model is essentially a weighted linear combination of features.
Span. The set of all possible linear combinations of a set of vectors. If vectors can generate an entire space, they are said to span that space. Example: two non-parallel vectors in 2D span the entire plane. In ML, feature representations span information space and embeddings span semantic spaces.
Basis. The minimum set of vectors required to span a space. The vectors must be linearly independent — no redundant vectors allowed. Example: {(1,0), (0,1)} forms the standard basis of R².
Dimension. The number of basis vectors required to represent a space: a line has dimension 1, a plane 2, space 3. Modern ML systems often operate in hundreds, thousands, or millions of dimensions.

Part 3 · Core operations

Dot product

The dot product measures similarity between vectors: x·y = Σ xᵢyᵢ = ‖x‖‖y‖cos θ where θ is the angle between the vectors. Large positive → similar direction; zero → orthogonal; negative → opposite direction.

Norms

L2 norm. ‖x‖₂ = √(Σ xᵢ²) — measures straight-line distance. Applications: gradient descent, regularization, distance metrics.
L1 norm. ‖x‖₁ = Σ |xᵢ|. Applications: sparse models, Lasso regression, feature selection.

Orthogonality

Two vectors are orthogonal if x·y = 0. Orthogonal vectors are independent in direction.

Part 4 · Projections & least squares

Projection formula

Projection measures how much one vector lies along another vector.

projy(x) = x·yy·y y Applications: dimensionality reduction, signal processing, PCA, optimization.

Orthogonal decomposition

Any vector can be decomposed into x = x̂ + e, where x̂ is the projection and e is the orthogonal error component. This concept forms the geometric intuition behind regression error minimization.

Interactive · Projection explorer constructed example

Least squares (extremely important)

Given Ax = b, often an exact solution does not exist. Least squares finds the best approximate solution by minimizing squared error. Normal equation: x = (AᵀA)⁻¹Aᵀb

Part 5 · Matrices & transformations

Matrix multiplication. C = AB combines transformations. Matrix multiplication is not commutative: AB ≠ BA in general. Order matters significantly in ML pipelines.
Matrix-vector product. Ax is a linear transformation — rotation, scaling, or projection. Neural network layers internally perform repeated matrix-vector multiplications.
Identity matrix. Behaves like multiplication by 1: Ix = x. Used extensively in matrix inversion, optimization, and residual connections.
Transpose. Swaps rows and columns: (Aᵀ)ᵢⱼ = Aⱼᵢ. Important in covariance computation, backpropagation, and linear algebra proofs.
Symmetric matrix. A matrix is symmetric if A = Aᵀ. The covariance matrix is symmetric. Symmetric matrices have real eigenvalues and orthogonal eigenvectors — properties essential in PCA, spectral methods, and optimization.

Part 6 · Rank & linear independence

Linear independence. Vectors are linearly independent if a₁x₁ + a₂x₂ + … + aₙxₙ = 0 forces every aᵢ = 0. Meaning: no vector can be represented using the others — no redundancy exists.
Rank. The number of linearly independent columns (or rows) in a matrix. Full rank → no redundancy; low rank → redundant features. ML insight: the multicollinearity problem; PCA reduces rank.

Interactive · Independence checker (2D) constructed example

Two 2D vectors are independent exactly when their determinant is non-zero. Add a third vector: in R² the rank can never exceed 2, so any third vector is redundant.
