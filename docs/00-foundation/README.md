# Foundation

This directory fixes the long-lived intent of Learning OS. It answers what the project is, why it exists, what it refuses to become, and the shared language required to make consistent decisions.

- [Charter](charter.md) — vision, mission, scope, success measures, and invariants.
- [Principles](principles.md) — decision-making priorities and trade-offs.
- [Glossary](glossary.md) — controlled vocabulary used throughout the repository.
