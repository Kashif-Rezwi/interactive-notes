# Design Principles

Use these principles in order when a trade-off has no explicit decision record.

1. **Learning outcome over feature novelty.** A capability exists to help a learner build, test, and retain a mental model.
2. **Evidence over fluency.** A persuasive response without source grounding, evaluation, or uncertainty disclosure is incomplete.
3. **Plan before generation.** A teaching plan and artifact specification constrain creativity into a reviewable result.
4. **Evaluate before retrying.** Revisions must target observed defects, not random variation.
5. **Preserve provenance by default.** Keep input identity, transformation lineage, and reviewer decisions with the work.
6. **Compose narrow roles.** Each agent, document, prompt, rubric, and record owns one responsibility and has defined boundaries.
7. **Prefer explicit contracts to tacit coordination.** Handoffs use named artifacts and acceptance criteria.
8. **Separate durable memory from transient logs.** Logs describe what happened; curated memory states what should guide future work.
9. **Make quality measurable and contestable.** Scores require rubric evidence, calibration, and a route for human override.
10. **Optimize for repairability.** History, alternatives, source material, and rejected ideas make mistakes recoverable.
11. **Protect learner trust.** Do not overstate correctness, personalization, accessibility, privacy, or measured learning gains.
12. **Earn complexity.** Add process, agents, storage, and automation only when their value outweighs their coordination cost.
