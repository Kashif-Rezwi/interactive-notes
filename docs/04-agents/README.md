# Agent Architecture

**Status:** Approved<br>
**Owner:** Repository maintainer<br>
**Review by:** 2026-11-04<br>
**Applies to:** All child documents unless they declare direct metadata.

Learning OS uses a multi-agent system organized around independent accountability, not persona proliferation. The [agent catalog](agent-catalog.md) defines the 18-role reference architecture — the permitted role vocabulary; the [Stage 1 operating profile](stage-1-operating-profile.md) activates five composite profiles as the roles currently operating; the [coordination protocol](coordination-protocol.md) defines how they collaborate.
