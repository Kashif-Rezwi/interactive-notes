# Prompt Architecture

**Status:** Approved<br>
**Owner:** Repository maintainer<br>
**Review by:** 2026-11-04<br>
**Applies to:** All child documents unless they declare direct metadata.

Prompts are governed product assets. This directory defines their taxonomy, lifecycle, versioning, testing, and review. The prompt registry is [library/prompts](../../library/prompts/README.md); during Stage 1 it also holds Draft cards registered per [ADR-0004](../adr/0004-lesson-standard-adoption.md) — currently [PRM-generator-lesson-standard@0.1.0](../../library/prompts/prm-generator-lesson-standard@0.1.0.md) — and promotion to Approved follows the [prompt versioning and promotion](prompt-versioning.md) process. Use the [prompt template](../../templates/prompt/prompt-card.md) for new draft work.
