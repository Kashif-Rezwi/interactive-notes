# Operating Cadence

**Adoption state:** Future capability — the weekly/monthly/quarterly ceremonies begin when Stage 2 automation and team capacity exist. Current Stage 1 practice is the per-run row only (intake, lineage check, evaluation, reflection, memory disposition), evidenced in `records/`.

| Cadence | Activity | Outcome |
| --- | --- | --- |
| Per run | Intake, lineage check, evaluation, reflection, memory disposition | Complete accountable run |
| Weekly | Cluster failures, review blocked work, curate tentative memory | Prioritized improvement backlog |
| Monthly | Prompt/model benchmark review, rubric calibration, accessibility and provenance sampling | Approved changes or explicit holds |
| Per release | Gate audit, release review, risk acceptance, documentation check | Accountable release decision |
| Quarterly | Architecture/ADR review, retention audit, roadmap/risk revision | Updated strategic direction |

Metrics guide discussion but do not replace evidence. Each cadence publishes decisions, owners, and due dates; unclosed actions remain visible in the next review.
