# Open Questions

These questions are intentionally unresolved. Do not decide them implicitly through a prototype or dependency choice; create an ADR when evidence and decision authority are ready.

| Question | Why it matters | Evidence needed | Decision gate |
| --- | --- | --- | --- |
| Which artifact families should launch first? | Determines evaluation, rendering, and expert needs | Learner research, pilot quality, implementation cost | Stage 3/4 product ADR |
| What learner data, if any, is necessary? | Affects trust, privacy, and architecture | Learning-value hypothesis, consent/legal review | Before any collection |
| What constitutes evidence of actual learning gain? | Avoids mistaking engagement for learning | Study design, baseline, ethical review | Before efficacy claims |
| Which model providers and deployment modes are acceptable? | Affects cost, privacy, reliability, and quality | Benchmark, risk assessment, portability plan | Before production automation |
| What visual/rendering technology best supports accessible interaction? | Affects implementation and artifact constraints | Prototype findings, accessibility/performance tests | Stage 4 architecture ADR |
| Which domains need stricter review? | Affects safe scale and service boundaries | Risk taxonomy, domain consultation | Before domain expansion |
| How should multilingual learning be evaluated? | Language changes pedagogy and accessibility | Multilingual benchmark and expert review | Before multilingual release |
