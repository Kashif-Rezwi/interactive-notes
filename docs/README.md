# Learning OS Documentation

`docs/` is the authoritative operating manual for Learning OS. Its numbered directories encode a recommended reading order:

1. Foundation — why the project exists and the principles that constrain it.
2. Product — learner value, artifact intent, and boundaries.
3. System — conceptual architecture and contracts.
4. Workflows — governed execution and the quality loop.
5. Agents — accountable roles and coordination.
6. Prompts — versioned behavioral assets.
7. Evaluation — measurable quality and release gates.
8. Memory — durable organizational learning.
9. Observability — lineage, logging, retention, and incident learning.
10. Operations — repeatable playbooks and cadence.
11. Governance — standards, versioning, reviews, and ADR policy.
12. Roadmap — maturity stages, risks, decisions still open, and implementation gates.
13. ADRs — immutable major decisions.

Read the [repository entry point](../README.md) first. Do not treat a document as authoritative merely because it is under `docs/`: status, owner, and linked decision determine its operational authority.
