# Approved Prompt Library

This directory contains prompt cards in `Approved` or `Deprecated` status; during Stage 1, cards may additionally be registered in `Draft` status pending the prompt promotion process (per ADR-0004). Experiments that have never produced a governed candidate belong in their work record until they pass the prompt promotion process.

Each card follows `templates/prompt/prompt-card.md`, carries a semantic version, declares compatible roles and evaluation evidence, and never includes private source material or credentials.
