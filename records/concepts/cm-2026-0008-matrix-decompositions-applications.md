## Scope and learning boundary

The lesson reorganizes the source into five dependency-ordered units: invariant directions, diagonalization, SVD, PCA, and low-rank approximation. It adds only the FOUNDATION bridges needed to read matrix products, transpose, variance, and rank. It does not teach numerical eigensolvers or a full proof of the SVD.

## Atomic claims and evidence anchors

1. Eigenvectors preserve direction while eigenvalues scale magnitude (cells 3–6).
2. The characteristic equation identifies eigenvalues as determinant roots (cells 9–11).
3. A diagonal matrix raises to a power entry-by-entry (cells 13–16).
4. Diagonalization requires enough independent eigenvectors (cell 15).
5. SVD applies to every real matrix, including rectangular matrices (cells 18–20).
6. U and V describe output and input directions; Sigma supplies axis scales (cells 20–23).
7. Singular values connect to eigenvalues of A^T A through a square root (cell 25).
8. PCA seeks high-variance, low-redundancy directions (cells 27–29).
9. For centered X=U Sigma V^T, columns of V are principal directions and squared singular values encode variance scale (cells 28–29).
10. Keeping top-k singular values trades detail for compression and denoising (cells 32–35).
11. Low rank models hidden user, image, language, or model structure (cells 36–40).

## Prerequisites and relationships

vector and matrix → matrix transformation → eigenvector/eigenvalue → diagonalization → transpose and singular value → SVD → centered data and variance → PCA → rank and truncation → low-rank approximation → ML applications. The source's application names are introduced only after the mechanism they use.

## Examples, non-examples, and misconceptions

**Examples:** diag(2,3) with eigenvectors [1,0] and [0,1] (cell 6); A^100 through D^100 (cell 15); compression by dropping small singular values (cells 22–24, 32–35); centered-data PCA (cells 27–29).

**Non-examples:** a rotated vector that changes direction is not an eigenvector; an arbitrary matrix is not diagonalizable when it lacks independent eigenvectors; dropping a large singular value is not a harmless compression.

**Misconceptions:** eigenvalue means an entry of A; every vector is an eigenvector; diagonalization is repeated multiplication; SVD only works for square matrices; smaller singular values are always meaningless noise; PCA is unrelated to SVD; rank-k means keeping k arbitrary entries; compression preserves every detail.

## Ambiguities, gaps, and assumptions

The source writes Sigma and V^T informally and does not give a numeric SVD. The lesson supplies one small constructed 2x2 diagonal example and marks it constructed. The claim that smaller singular values are "likely noise" is softened to "can carry less dominant structure"; no universal noise claim is made.
