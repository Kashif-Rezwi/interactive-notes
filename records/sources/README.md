# Source Identity Records

Store the immutable source-identity records that anchor the traceability graph. Each record identifies the exact source bytes (SHA-256), origin and capture history, language and scope, and the citation anchors used by the concept model and run ledgers.

Creating a record here is an owner act: the record's existence is the documented authorization that the source may enter the governed workflow (P0 of the [lesson generation workflow](../../docs/03-workflows/lesson-generation-workflow.md)). Use [SRC-2026-0001](src-2026-0001-aiml-4-module-02.md) as the structural exemplar when adding a source.
