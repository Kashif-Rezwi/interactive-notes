# Templates

Templates standardize evidence and handoffs without imposing runtime formats. Copy the smallest applicable template, retain its required headings, assign a stable ID, and link the completed record from its authoritative index or run ledger.

| Template | Use |
| --- | --- |
| [ADR](adr/adr.md) | Durable architectural decision |
| [Documentation](documentation/document.md) | New or materially revised authoritative document |
| [Prompt card](prompt/prompt-card.md) | Versioned prompt asset |
| [Run record](run/generation-run.md) | One generation/revision lifecycle |
| [Evaluation report](evaluation/evaluation-report.md) | Rubric-based scoring and release recommendation |
| [Memory item](memory/memory-item.md) | Curated reusable lesson |
| [Experiment](experiment/experiment.md) | Bounded hypothesis and comparison |
| [Playbook](playbook/playbook.md) | Repeatable operating procedure |
| [Lesson specification](lesson/lesson-specification.md) | Learner-facing artifact intent before generation |
