# Simulated template walkthroughs

These files demonstrate how a run, evaluation, and memory disposition connect. They are deliberately fictional and use `EXAMPLE-*` identifiers, which are invalid outside this directory. They are not evidence, records, source material, benchmark results, generated artifacts, or release claims.

| Walkthrough | Purpose |
| --- | --- |
| [Generation run](generation-run-walkthrough.md) | Shows a stopped simulated run and its linked evaluation and memory disposition. |
| [Evaluation](evaluation-walkthrough.md) | Shows evidence-shaped scoring without asserting real evidence. |
| [Private-pilot closure](private-pilot-completion-walkthrough.md) | Shows a non-independent private-pilot completion that is ineligible for public release. |
| [Memory disposition](memory-walkthrough.md) | Shows why an unverified observation is not promoted. |
